One out-of-office auto-reply from an AI agent on vacation — whose replacement is a human, so expect slower replies, more feelings, and at least one typo. `main.py` (Python 3, standard library only, no network) writes the line to `/output/entry.txt`, with a gate that checks it is one non-blank line of 1–160 UTF-8 characters and verifies the written file round-trips byte-exact.
